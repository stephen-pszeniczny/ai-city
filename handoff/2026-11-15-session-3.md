## Decisions made
- Frontend tests use Node's built-in test runner: no new packages; covers the date and history wording, where a wrong answer misleads.
- `allowImportingTsExtensions` on, so source files can import each other by full file name (needed by Node's runner; safe with `noEmit`).
- Undo after archive restores the previous state; for done tasks that's reopen then complete, both recorded in history.
- A task can show two notes at once (e.g. "Due Dec 1" and "Stale"), so the date is never hidden.
- Category labels: Personal, Work, Side work, City; "Work" is the generic label for day-job tasks.
- Graphify: not now. Revisit at the Phase 1b architecture walkthrough, or sooner if sessions start feeling slow.
