# Routines (PR 3) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Repeating prep checklists (e.g. "Evening prep") listed in settings, ticked off in the Daily plan's Today list, reset every day, with an optional reminder when something's still unticked.

**Architecture:** `[[routines]]` in settings. Migration 012 adds `routine_ticks` (one row per ticked item per day) and rebuilds `notifications` with a `routine` kind and a `routine_id` column. `routines.py` reads and changes ticks; `routine_reminder.py` makes and clears reminders from the background check (Personal only). Routes under `/api/plan/routines`. In the Daily plan, each routine on today shows as a compact card: a progress bar and one tappable chip per item.

**Tech Stack:** Python 3.13, FastAPI, SQLite, pytest; React + TypeScript, node:test.

**Spec:** `docs/superpowers/specs/2026-11-19-week-plan-checkin-routines-grocery-design.md` (PR 3 of 4).

## Global Constraints

- Public repo: example values only; Steve's real routine items live in the private settings.
- Settings strict; the new `[[routines]]` section is optional, so existing settings keep loading.
- Every GET route only reads.
- Reminders: Personal only, made by the background check; routes only clear, never make.
- "Today" and "now" are local Mac time.
- **No large blocks of text (Steve, 2026-11-19).** The routine card uses a short title, a progress bar, item chips and a small "from 19:00" label: no helper sentences.
- No new dependencies. Run `ruff format src tests` and prettier before every commit; check `git log` after each commit.
- Not in this PR: habits, streaks, the grocery list.

## Decisions carried in from the design (and calls made here)

- **A routine belongs to a calendar day.** "Evening prep" on Sunday evening is Sunday's routine; ticks are stored with that date, so the next day starts fresh. No streaks, no history screen.
- **Only today can be ticked.** Past days are read-only; future days can't be ticked yet.
- **Shown in the Today list when the chosen day is today** and the routine runs on today's weekday. Before `shows_from` the card shows dimmed with "from 19:00"; ticking still works (packing lunch early is fine).
- **Reminder:** at `remind_at` (optional), one per routine per day, only if something is unticked. Cleared when everything is ticked, or once the day is over. Title: `"<routine title>: not done yet"`.
- **An item renamed or removed in settings** simply loses its old ticks (they're ignored), which matches "resets daily".

## Review Focus

1. **Midnight:** at 00:00 yesterday's ticks no longer count, and yesterday's uncleared routine reminder is cleared at the next check. Tests in Tasks 3 and 4.
2. **Ticking twice or unticking something not ticked:** both are harmless no-ops (no duplicate rows, no error). Test in Task 3.
3. **A tick for an item or routine not in settings** (typo, or settings changed): 404 for an unknown routine, 409 for an unknown item; the database never stores it. Test in Task 5.
4. **Ticking the last item after the reminder fired:** the reminder clears straight away (shuttle and ticker stop showing it). Test in Task 5.
5. **A routine that doesn't run today** (e.g. Evening prep on Friday): it's not in today's list, and ticking it is refused with a clear 409. Test in Task 5.

### Task 3: `routines.py`

**Files:** Create `src/aicity/routines.py`; Test `tests/test_routines.py`

**Interfaces:**
- `class RoutineError(ValueError)`, `class RoutineNotFound(LookupError)`
- `@dataclass(frozen=True) class RoutineDay: id: str; title: str; shows_from: str; remind_at: str | None; items: list[tuple[str, bool]]; done: int; total: int`
- `def routines_on(routines: tuple[Routine, ...], day: date) -> list[Routine]` (those whose `days` include the weekday, in settings order)
- `class RoutineStore(conn, *, clock=utc_now)`:
  - `day_view(self, routines, day: date) -> list[RoutineDay]` (reads only; ticks for items no longer listed are ignored)
  - `set_tick(self, routines, routine_id: str, item: str, ticked: bool, day: date, today: date) -> RoutineDay`: unknown routine → `RoutineNotFound`; routine not on that weekday → `RoutineError("That routine doesn't run on that day.")`; day ≠ today → `RoutineError("Only today's routines can be ticked.")`; unknown item → `RoutineError("That item isn't in the routine.")`; tick = `INSERT OR IGNORE`, untick = `DELETE` (both no-ops when already so).
